# 🌊 Release — YourBlog

A full-stack blog app where users can write, edit, and delete posts freely.

## 🛠 Built with
Node.js · Express.js · EJS · CSS · body-parser

## ✨ Features
- Create, read, update, and delete blog posts (full CRUD)
- Dynamic content rendering with EJS templates
- Form handling via POST requests and body-parser
- Multi-route structure for all user actions
- Styled UI with header and footer layout

## 🚀 Run locally
```bash
npm install
node index.js
```

## 🧠 What I learned
This was my first full-stack project — It took me 3 weeks of wrestling with data flow between EJS and Express, debugging routing logic, 
and figuring out index-based CRUD to get it to this state. This is the hardest project I've done so far but it has been super rewarding to finish and to see the final outcome.
